#### Décisions

| Décision | Pourquoi |
|---|---|
| Résumé de carte limité à 200 caractères et carte assez haute pour l'afficher en entier | La cliente choisit elle-même où couper (repère `---`), sans « … » sur le site |
| Hauteurs réglées dans `EducationCard`, pas dans `BaseContentCard` | Le socle est partagé par les autres cartes du site |
| Journal de bord quotidien, un fichier par jour | Plus facile à relire et à compléter en fin de session |
| Deux libellés distincts sur les actions terrain : « Pays où le projet a été réalisé » / « Pays concerné (financeurs) » | Le rattachement n'est pas le lieu de l'action |
