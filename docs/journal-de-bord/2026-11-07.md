# 7 novembre 2026 — Erreurs HTTP justes (404 / 409 / 403), suite de tests unitaires et front, documentation

**126B — Codes d'erreur de l'API :**
- Erreurs Prisma traduites une seule fois, dans le gestionnaire global de `app.js` (`utils/prismaErrors.js`) : `P2025` (introuvable) → **404**, `P2002` (doublon) → **409**
- Origine CORS refusée → **403**
- Pays du dashboard triés à la française (`localeCompare(…, 'fr')`)

**126 — Tests :**
- Backend : tests unitaires (`tests/unit/` : utils, jwt, authMiddleware, sans base) + intégration auth, routes publiques, sécurité, contact, 404 des CRUD
- Frontend : tests unitaires, composants et pages (API simulée) + `duplicatedRules.test.js`, qui échoue si une règle dupliquée front / back diverge
- Environ 400 tests au total

**Documentation :** `bugTracker.md` (BUG-56 à 66), `modif-en-cours-de-dev.md` (modifications 60 à 66), planning à jour

#### Bugs rencontrés et résolus

| Bug | Problème | Solution |
|---|---|---|
| BUG-60 | PATCH / DELETE / pause sur un id inexistant → 500 (8 ressources) | Traduction globale de `P2025` → 404 |
| BUG-61 | Origine non autorisée → 500 | `error.status = 403` + test |
| BUG-62 | « Égypte », « Équateur » rangés après « Zimbabwe » | Tri `localeCompare` en français |
| BUG-63 | Tests backend hors Docker : `prisma.partner` undefined | Client Prisma du poste périmé → tests d'intégration lancés dans le conteneur |
| BUG-64 | Vitest dans le conteneur : import du backend introuvable | Test de cohérence front / back exclu du conteneur (`existsSync`) |

| Décision | Pourquoi |
