#### Bugs rencontrés et résolus

| Problème | Solution |
|---|---|
| Une modification (PATCH) vidait les champs non envoyés | Seuls les champs présents dans la requête sont modifiés (même correction pour le rattachement) |
| Lint `react-refresh/only-export-components` : une fonction exportée depuis un fichier de composant | `isValidButtonUrl` déplacée dans `utils/validation.js`, front et back, vérifiée par `duplicatedRules.test.js` |
| Tests d'intégration des sections et des cartes en conflit (nettoyage en parallèle) | Les deux dans un seul fichier |

#### Décisions

| Décision | Pourquoi |
|---|---|
| Un seul type de section générique | La cliente peut ajouter un nouveau projet sans développement |
| Rattachement en `enum` sur un seul champ, pas de table de liaison | Un contenu n'est rattaché qu'à un pays (ou aux deux) |
| Colonne facultative en base, obligatoire dans les formulaires | Les contenus existants ne bloquent pas la migration |
| Prix en texte libre (« Gratuit », « Sur devis ») | La cliente écrit le tarif comme elle le veut |
